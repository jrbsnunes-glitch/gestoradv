# GestorAdv — resumo para e-mail

**O que é:** plataforma de gestão para escritórios de advocacia — processos, clientes, prazos, tarefas, financeiro (caixa, contas a pagar, rateio escritório/advogado), dashboard, relatórios, gestão de advogados, inbox de atendimento e integração com WhatsApp (com IA opcional). Dados do escritório em um só lugar; modelo SaaS ou instância dedicada.

**Por que usar:** menos risco com prazos (alertas), visão financeira clara, atendimento moderno via WhatsApp alinhado ao jurídico.
